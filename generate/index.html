    Generate Poses

    Generate poses from geometrical annotations

    napari-tomoslice generate-poses [OPTIONS] COMMAND [ARGS]...

    Poses can be sampled in a number of ways from each annotation type:

    • Points
    • Spheres
    • Path: Backbone, Helix, Rings
    • Dipoles: Direct, Disk
